# Save animation stacks as named, reusable packages

## Goal

Let a user save a tuned stack of animation packages on one element (e.g. Breathe + Coin Spin + Drift with their dial values) as a named package, such as "Hypno", that then appears in every Transform's "+ Add animation" picker alongside the built-ins and adds the whole stack in one tap. Stored as named presets in their own folder, like beat presets (`beatpresets/`, `BeatPresetLibraryNode`). Open to design once ct#20's built-ins are in use: whether a saved stack captures only dial values or also the bindings and triggers on those dials, and whether applying it adds to or replaces an element's existing animations.

## Dependencies

- [20 Named animation packages with their own dials](20-named-animation-packages-with-their-own-dials.md) — builds on ct#20's built-in packages and per-Transform Animations list
