# Gradient-based palette designer

## Goal

A palette design tool (likely in the remote UI) where colour stops are placed along a line with curves/gradients between them, like PowerPoint's gradient designer. The generated palette is sized to hold every step rather than being fixed at 256 entries — IndexPaletteRenderer and the 256×N LUT layout already accept any entry count. From ideas.md #2.
